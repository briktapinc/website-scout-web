MCP

One Streamable HTTP server for Cursor, Muse, Claude, and VS Code (URL + Bearer). ChatGPT reaches the same server through OpenAI’s Secure MCP Tunnel (tunnel-client → localhost), or via a public HTTPS /mcp URL.

HTTP MCP (Cursor · Muse · ChatGPT tunnel target)

Starts the Streamable HTTP listener. Cursor and Muse connect with the JSON below (url + Bearer). For ChatGPT, keep this running and point OpenAI tunnel-client at http://127.0.0.1:<port>/mcp — see the ChatGPT tunnel example under the config block. Set a custom public URL for MagicDNS / Tailscale Serve if you want remote URL clients.

Use the full /ws endpoint (same as in Copy Tailscale config). A base URL without a path is OK — /ws is added automatically. Changing the listen port restarts HTTP MCP when this app started the listener.
